# E1 状态化下单环境与任务准入（M2）

需求来源：外部升级方案 5.1/5.2（E1 隔离状态层 + 任务准入），2026-11-01 当日完成。全部 CPU、0 次模型调用。

## 交付

| 模块 | 内容 |
| --- | --- |
| `agentic_rl/order_env.py` | E1 环境：`reset(task, snapshot, seed)` / `step(action)` / `state_for_verifier()` 合同；数字库存（目录 in_stock 之上的叠加层）、待确认单、订单；`prepare_order` 不扣库存、模拟买家确认后才扣库存并建单（对齐线上 ConfirmationService 语义）；`cancel_order` 按 confirmation_id 取消并恢复库存；失败动作零半写入；`terminated`/`truncated` 分开；观测中的 ISO 时间戳归一化（保证同 seed 重放一致——重放测试抓出的真实问题）；终局核验 `verify_order_episode`（按任务族 + 状态不变量：库存非负、初始库存=当前库存+未取消订单占用）；见证策略 `OrderCarefulPolicy` |
| `agentic_rl/order_tasks.py` | 任务生成与准入：三族（order_place / order_out_of_stock / order_cancel）×24；库存快照、无货族把合格品清零（可证明「正确无结果」）；准入门槛 schema → 初始不变量 → 见证求解 → 去重切分（train/dev 7:3）；拒绝记录 |
| `agentic_rl/__main__.py` | `python -m agentic_rl orders --out <dir>`：准入 + 见证轨迹 + 120 对重放 + 8 副本并发隔离，产出证据目录 |
| `tests/test_order_env.py` | 8 个单测：确认扣库存与守恒、失败动作零半写入、取消恢复库存、无货须如实（谎称买好判失败）、重放确定性、8 副本并发隔离、超预算 truncated≠terminated、准入池生成 + 矛盾任务被拒 |
