## 问题与本次变更

AgentScope 2.0.8 的结构化生成可能在 forced / auto / none 策略间回退。上一条流若仍占用共享限流名额，下一次请求会等待自己释放资源，出现卡住。

- 锁定 AgentScope 2.0.8 及依赖，适配原生审批、上下文压缩和结构化输出。
- 每次结构化生成尝试结束先关闭本次流、释放限流名额；格式错误、取消及回退路径同样处理。
- 每次底层请求分别结算 usage 与预算；供应商未提供的 usage 保持未知。
- LoopDetector、已有记忆和分层上下文治理继续保留，没有因 SDK 升级移除。

源码入口：[模型适配](../../../app/infrastructure/llm.py)、[依赖定义](../../../pyproject.toml)、[锁文件](../../../uv.lock)。
