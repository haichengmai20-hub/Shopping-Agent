## 需求与本次变更

在 v2 的 1,000 件商品上增加 27 个“平台 × 语种”组合，每组 100 件，最终 **3,700 件商品、7,105 个 SKU**。每组覆盖 25 类商品的 4 种规格，旧商品和 SKU 保留。

| 平台 | 新增语种 | 新增 / 当前总量 |
| --- | --- | --- |
| Amazon | 英、西、德、法、日、荷、波、瑞典语 | 800 / 1,050 |
| eBay | 英、西、德、法、意、荷、波兰语 | 700 / 950 |
| Etsy | 英、西、德、法、意、日、荷、波、葡萄牙语 | 900 / 1,150 |
| Walmart | 英、西、加拿大法语 | 300 / 550 |

语种按站点与语言支持选择，“常用/长尾”是工程覆盖分组，不是官方销量排名；所有新增 listing、品牌、评分和报价都是合成演示数据，非真实抓取。

标题、描述、属性与 SKU 规格提供对应语言正文；内容语言、locale、配送地和币种分别记录。BM25 增加 Unicode 标准化、汉字/假名二元词项和低权重子词，带数字或连接符的型号保持完整；不把隐藏中文译文混入外语检索。

库存启动改为事务内批量读取库存及历史订单占用，再补新 SKU 和更新报价。服务重启不会重置已扣减库存。默认目录与镜像改为 v3，旧 v1/v2 数据及其评测底座保留。

源码入口：[目录生成](../../../scripts/generate_catalog_multilingual.py)、[语言数据](../../../scripts/catalog_multilingual_data.py)、[BM25](../../../app/infrastructure/retrieval/bm25.py)、[库存事务](../../../app/infrastructure/persistence/sql/trade_store.py)。

## 验证与边界

616 条诊断按平台和目标语种切片：同语种 Recall@5 从 82.33% 到 94.68%；英语查其他语种从 13.27% 到 26.22%；中文查外语维持 9.26%。无库存/配送硬约束违规，仍有荷兰语等漏召回。

这不是全目录 3,700 件的独立留出验收；小切片耗时和词项收益不代表完整 Agent 或跨语言向量效果。真实 embedding / Qwen 精排仍阻塞。
