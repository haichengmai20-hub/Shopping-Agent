## 问题与本次变更

切换 embedding 模型或维度后，旧向量与新查询不兼容，不能继续直接计算相似度。本次增加受控重建；同时修正 Prompt 中旧的记忆维护工具签名。

- 校验查询与存储向量的类型、维度、有限值和非零范数，跳过无效或不兼容向量。
- 对不兼容记录重新计算向量；模型调用在数据库事务外执行，不重新提炼事实。
- 事务内通过买家、事实 ID、版本及原索引 CAS 更新，防止并发删除或编辑后被旧重建覆盖。
- 重建批次失败不写入，保留原索引；兼容的新向量仍可召回。召回前再次检查当前事实版本。
- 同步记忆更新/删除工具的 ID、版本等必需参数说明，增加 Prompt 与实际 schema 的一致性回归。
