## 问题与本次变更

刷新或切换页面后，整理操作可能仍在服务端运行；页面不能仅凭组件本地状态重新允许提交，也不能让旧会话的迟到结果覆盖当前会话。

- 整理状态放在 App 会话层维护，切换工作区页面时继续恢复和轮询。
- 即使浏览器没有缓存消息，也查询服务端上下文和活动操作。
- 使用 generation 与读取版本排除旧响应；提交期间加锁，携带 request_id 与 expected_revision。
- 完成后读取最新摘要和 revision；提交失败重新查询权威状态，保留摘要并允许后续重试。
- 运行中或有待审批操作时禁止手动整理。
