## 需求与本次变更

在应用层将 BM25 与 Qdrant 稠密向量用加权 RRF 融合，保留权威目录过滤和候选补召回。没有使用 Qdrant 稀疏索引。按本次需求撤除聊天模型精排，工厂只接受 `http / disabled`；旧 `llm` 配置直接报错。

专用 HTTP reranker 增加独立密钥、超时和 flat / DashScope 协议设置，保留完整接口路径。HTTP 200 中的业务错误、空响应、缺项、重复索引和非有限分数都视为失败。完全相同文本只请求一次评分，再映射回原商品位置，不把 SKU、价格或配送条件合并。

源码入口：[检索用例](../../../app/application/usecases/catalog_search.py)、[BM25](../../../app/infrastructure/retrieval/bm25.py)、[HTTP 精排](../../../app/infrastructure/rerank/http_reranker.py)、[工厂](../../../app/infrastructure/rerank/factory.py)、[依赖预检](../../../scripts/retrieval_preflight.py)、[本机模型服务](../../../scripts/retrieval_server.py)。

## 验证与结果

先构建 4 平台各 250 件的 v2 合成目录；18 条开发场景与 54 条留出场景分开。使用真实本机 BGE embedding、Qdrant 和专用跨编码器精排，与旧词项、BM25、纯向量及混合召回对照。

四条金标错误纠正后，对同批输出重计分：混合加精排 Recall@5 为 98.96%、NDCG@5 为 0.9682，模块 P95 为 913.8 ms。**这是标签纠错敏感性分析，不是新一轮独立留出验证，也不是指定 Qwen 模型结果。** 仍有排序失败，单独混合召回的收益区间跨零。

完整方法、原始与重算结果、失败样本见[千件检索报告](../../../eval/verification/retrieval-1000-20260918/REPORT.md)。确定性检查见[混合检索测试](../../../tests/test_hybrid_retrieval.py)、[精排协议测试](../../../tests/test_reranker_client.py)。
