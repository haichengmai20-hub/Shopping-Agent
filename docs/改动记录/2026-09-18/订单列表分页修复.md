# 2026-09-18 · 订单列表分页修复

状态：前序修复在本次合并发布，前端回归通过；开发日期未逐项核实。关联代码：`be13ff48`。

## 问题与本次变更

买家按状态筛选订单，停在最后一页；取消该页唯一订单后，列表总数下降，原 offset 可能超出范围，页面出现空白而前面的订单仍存在。

刷新列表时根据服务端 total 计算最后有效页。当前 offset 超出范围就清理旧详情、切回最后有效页并重新查询；读取版本用于阻止旧请求覆盖新页面。

源码入口：[我的订单](../../../frontend/src/components/MyOrders.tsx)。
