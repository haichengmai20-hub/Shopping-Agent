## 真实服务验证

环境：单 API worker、真实 qwen3-max 网关、text-embedding-v4、本地 Qdrant、SQLite。最终初始化成功：500 件商品、1024 维向量，45 篇知识文档；Redis 未启用。

命令（工程根目录）：

```bash
uv run python scripts/verify_ag_ui.py \
  --base-url http://127.0.0.1:8000 \
  --query '推荐三款 300 元以内、寄到中国的旅行背包' \
  --output eval/ag-ui-verification-20260909.json
```

[实际报告](../eval/ag-ui-verification-20260909.json) 返回 `ok: true`。官方 Event schema、run/text/tool ID 和生命周期校验通过；最终状态 completed，3 件商品 P1049/P1003/P1017；12 次工具参数增量、1 个工具结果、91 次文本增量、最终消息快照均正常收口。

该样例首事件 **87 ms**、首段文本 **4.46 s**、总耗时 **12.83 s**，包含真实网关等待，仅为本次样例测量，不作为稳定延迟或前端 INP 指标。

重排服务返回“未找到模型对应的服务”，故报告如实记录 `recall_strategy: embedding_only`、`rerank_applied: false`。**协议与页面链路通过；正式 online-main 检索质量门禁未评测，重排主链没有通过验收。** 第一次启动还曾出现 embedding 超时，后续完整重试成功，没有用模拟向量代替。

使用实际 React 页面和正式构建产物，无前端演示数据注入。最终预览运行在 `http://127.0.0.1:5174`（`npx vite preview --host 127.0.0.1 --port 5174`），开发页为 5173。

- 真正执行 1 元上限查询：显示无结果，页面商品数为 0，不残留上一轮结果。
- 新查询清除旧比较；停止后页面显示已停止。修复并重启后再测，服务日志明确记录对应 run 已中断，没有此前的 KeyError。
- 详情默认 SKU 到手价显示正确；选雾霾蓝后旧到手价失效，比较表显示雾霾蓝及对应币种/价格。
- 收藏可在本机收藏页查看；历史在耳机与背包会话之间切换时分别恢复 0/3 件商品；重新打开浏览器页面后仍能恢复保存的历史。失效存储与跨 run 隔离另有自动化测试覆盖。

- Escape 关闭弹层并恢复触发按钮焦点；Tab/Shift+Tab 保持在弹层内。
- 服务未就绪时实测 HTTP 500，页面显示错误及重试入口；客户端测试另覆盖中文错误提示与服务器错误页不直接渲染。
