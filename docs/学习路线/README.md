# Globex 时间紧张版学习路线

这套材料以当前 Globex 项目为学习对象，以 [时间紧张版教程导读](../../docxs/Globex_教程导读_时间紧张版.docx) 的阶段顺序为主线。先读项目的实际调用链和源码，再按需查阅 docxs 中的概念解释。教程中的设计、历史示例和当前运行代码需要分别核对。

## 阶段目录

| 阶段 | 学习目标 | 当前材料 |
| --- | --- | --- |
| 1．项目地图 | 解释服务怎样启动、一条请求怎样走完，以及前后端分工 | [项目地图与前后端流程](01_项目地图与前后端流程.md) |

## 后续阶段的讲解约定

每个阶段先在对话页面给出完整讲解和作业，经过用户认可再写入本目录。开头明确本阶段正在学习 Globex 的什么功能，并对应到买家操作或项目工程任务。每份材料都包含该阶段的前端、后端及相关工程概念的直观解释：概念是什么、在 Globex 的哪个文件里、它解决了什么问题、数据怎样跨越前后端边界。作业包含手写 plain text 流程图、几个需要用自己语言回答的问题，以及完整参考答案与自查标准。答案放在题目之后，便于先独立完成。

学习资料默认只解释和引用项目源码，不修改 docxs 原件。模型 API、商品样例和运行状态以当次项目证据为准；阅读代码不等于真实服务或效果已经验收。
