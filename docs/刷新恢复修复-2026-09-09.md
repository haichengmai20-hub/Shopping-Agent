# 刷新恢复修复（2026-09-09）

用户反馈刷新后对话、长期偏好看起来消失。只读数据库核对发现，“喜欢小香风连衣裙”偏好及对应完整对话仍存在。用户原标签页运行旧版前端，首次原地刷新后已能看到新功能并读取原数据。

## 修复
- 当前会话指针与正文缓存独立读取；缓存缺失、损坏或被截断时，仍根据会话 ID 从服务端恢复。
- 缺少当前会话指针时，恢复当前买家的最新服务端对话。
- 明确开启的新选购保持空白，刷新不会被旧对话覆盖；迟到的初始化响应不会覆盖新提交。
- 指定买家身份也写入本机存储；买家切换时不继承前一买家的缓存及会话指针。
- 正文缓存写入失败时仍尝试保存会话指针。
- 当前导航位置保存在 sessionStorage，同一标签页刷新仍停留在偏好、Skill 或历史页面。
